## Current visual direction

The active system is:

> warm cream dotted DigiStream canvas + clean white/warm-white operational surfaces + dusty-pink brand anchor + restrained lavender/sky/mint/amber/peach supporting tints + compact Beautiful UI-quality component grammar + modern readable sans-serif typography.

The following legacy ideas are explicitly superseded:

- near-black application canvas as the default theme;
- emerald green as the primary brand action colour;
- dark mode as the default product presentation;
- green glow as a recurring visual signature;
- any instruction that conflicts with the current cream-dotted hybrid system.

## Historical/product intent

If an older section of this file is needed for product-history research, recover it from Git history. Do not restore its legacy visual rules into active agent instructions or current frontend styling.

Product behavior, authorization, lifecycle, media readiness, privacy, reliability and accessibility remain controlled by the current product documentation and implementation—not by this legacy file.
